# COVID-19 Dataset Analysis

## 📌 Project Overview
This project contains a COVID-19 dataset used for data analysis and dashboard creation. The dataset provides information about COVID-19 cases across multiple countries and states, including confirmed, active, recovered, and death cases. The goal is to analyze the spread of COVID-19 and visualize important trends using Excel or other data analysis tools.

---

## 📂 Dataset Description

The dataset contains COVID-19 statistics from **5 countries** and **7 states**.
<a
<a href="https://github.com/Sidduvinayak/Covid-19-Analysis-Dashboard/commit/33f33868a14303a50ae6dd210f72717bd75eaabf">Dataset</a>


### Features (Columns)

| Column Name | Description |
|-------------|-------------|
| Country | Name of the country |
| State | Name of the state/province |
| Date | Reporting date |
| Confirmed | Total confirmed COVID-19 cases |
| Active | Number of active cases |
| Recovered | Number of recovered patients |
| Deaths | Total deaths due to COVID-19 |

## 🎯 Project Objectives

- Analyze COVID-19 case trends.
- Compare confirmed, active, recovered, and death cases.
- Identify the most affected countries and states.
- Create an interactive dashboard.
- Generate meaningful insights from the data.
